# Empty-read agreement experiment

The two-slot supplied-address control fails before learned selection can be
tested. The retained [fixed-read run](results/heads-capacity-fixed-read.json)
stops on the first prefix after 42 and 21 completed rounds for founders 0 and
1. Both exposed controls acquire the training panel. This experiment tests one
local boundary change at the same anatomy, coupling, learning rule and solver
budget. It is a component experiment; it establishes no learned relevance,
semantic code, continuing-life behavior or multihead advantage by itself.

## Boundary law

For agreement memory, let `R(q)` be the softmax mixture of witnessed values,
including the zero-key, zero-content null. The historical instrument uses

```
E(q,r) = alpha/2 * ||r - R(q)||² * any_held
```

An empty bank therefore removes the read's restoring force while reciprocal
read/cortex connections remain active. The opt-in `empty_anchor=True` uses

```
E(q,r) = alpha/2 * ||r - R(q)||²
```

On an empty stream, `R(q)=0` and its query Jacobian is zero, giving read force
`-alpha*r` and query force zero. This is finite agreement with absent content;
it does not clamp the read to zero. Occupied streams use exactly the historical
equations. Fixed addresses use the same change with `R` held constant. Every
free, positive and negative phase includes the boundary in its full residual.
The linear and competitive controls keep their historical equations and reject
this agreement-only option.

The simpler control remains `empty_anchor=False`. Existing receipts and source
snapshots are retained. No library source or default changes. An independent
instrument cache repair clears the previous memory boundary on reset, so a
failed first event cannot restore a preceding trial's boundary as its cache.
It does not change the boundary actually used by a successful solve.

## Acquisition comparison

The frozen declaration compares both settings
on founders 0 and 1, using the existing supplied-address H2 control. It keeps
512 rounds, batch 16, the same training draws, alpha 1.5 per head, step `.1`,
tolerance `.003`, and the 2,048-sweep cap. The teacher still supplies both final
labels only on wrongly answered pairs. No head role or learned address is
claimed: the fixed A/B addresses are an explicit oracle capacity control.

The historical control must reproduce its refusal and learning trajectory.
Matched query drives, actual witnessed banks, neural teaching phases,
parameters and optimizer history are compared before the original refusal.
Prefix activity may differ; the source-only assay deliberately clears its
trace and warm state before the query. This identity argument does not apply
to general continuing brains with learned codes or state-dependent memory
writes.

Admission requires both anchored founders to finish all 512 rounds without an
action or lesson refusal, then reach the original `.95` exact-pair, each-slot,
unequal-pair and each-query floors on all 48 training cases. All 16 held-out
cases are reported separately. A single repaired settle, a small residual or
different attention weights cannot pass acquisition or establish a useful
second head. Learned selection, causal interventions, held-out transfer and
resource controls remain subsequent gates.
