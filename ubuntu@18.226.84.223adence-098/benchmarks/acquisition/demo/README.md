# Acquisition microscope viewer

A dependency-free viewer of **historical receipt summaries**, not a running
brain or a raw audit archive. It retains all four complete relation campaigns,
all twenty founders, every recorded readback checkpoint, failures, refusal/work
counts and saved continuation outcomes. The measurements used the recorded
`0.73.0` source; packaging them in a later release does not rerun them.

From a source checkout or extracted source distribution:

```sh
python -m http.server 8766 --bind 127.0.0.1 --directory benchmarks/acquisition/demo
```

Open `http://127.0.0.1:8766/`. **Open results** accepts another
`cadence.acquisition-demo.v1` export or bundled summary. Opening `index.html`
directly also works with file upload; local browsers may block automatic JSON
loading from a file URL. Replay navigates existing measurements and performs no
learning. No data is sent to an external service. This directory is included in
the source distribution, not the installed Python wheel.

These are graph-learning controls with teacher labels; they are not animal
competence, native-gameplay, matched efficiency or physical-energy claims.
Local RMS uses rates `0.003`/`0.0003`, RMS decay `0.99`, floor `0.001`, momentum
`0`, motor lateral `0` and leak `0.1`. All five public endpoints were replayed;
only seed 21's complete historical trajectory was independently regenerated.
Four histories remain unreplayed. The failed foreign-NumPy verification attempt
and both endpoint audits remain separately charged.

## What can be verified here

`bundle-manifest.json` records SHA-256 and size for the bundled display files.
`research-ledger.json` is a portable research summary: raw archive references
have explicit artifact IDs and `external_not_bundled` availability. They are
not broken local file links and are never fetched. `receipt-index.json` records
optional original-artifact identities, including the unmodified research ledger
and original exports. Every derived campaign summary names its original export
digest and the transformations used; duplicate legacy curve/example/endpoint
representations are removed, while `stages`, final scores, controls, work and
continuation remain.

**Check an optional external receipt file** accepts a local file up to 32 MiB
and compares its SHA-256 with that index. A match proves byte identity only. It
does not replay an equilibrium, regenerate learning, verify the entire source
census or establish behavioral success. Full scientific replay needs the
original retained protocol, source/runtime, inputs, phase arrays, checkpoints
and matching verifier. Those large/private artifacts are not distributed here.
An uploaded campaign is also displayed without a new scientific verification.

Frozen experiment references stay distinct from current publication snapshots.
Current roadmap or manifesto edits never substitute for source archived before
a run. See the [owning acquisition guide](../README.md) and the
[receipt contract](../../../docs/evaluate.md#receipts).
