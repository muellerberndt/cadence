route A=(0,1), route B=(2,3), rare emergency C=(4,5), neutral N=(6,7).

family two is the emergency response. The world never supplies a correct-action
label, phase ID, future value, teacher, bootstrap or salience override to the brain.

| World phase | A's rewarded action | B's rewarded action | C's safe action | N |
| --- | --- | --- | --- | --- |
| acquired A / matching routine A | 0 | 1 | 0 | reward 0 for either action |
| conflicting/revised B | 1 | 0 | 0 | reward 0 for either action |
| restored A | 0 | 1 | 0 | reward 0 for either action |

The world executes the sampled action returned by public non-greedy `act`.

yields `+1`, other action `-1`. The same signed scalar reward channel carries
relief/pain. `learn(reward, done, following)` receives that actual outcome once;
salience is the normal `abs(reward)`, explicitly an outcome-derived supplied

eligibility is rewritten. Unknown unexecuted actions remain masked, not zero
