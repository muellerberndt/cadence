## Portable instrument preparation

The release instrument includes resource/custody hardening and optional formal
source snapshots. These changes do not reattribute the scientific scores below:
the historical attempt used its exact frozen 0.73.0-era worker and library.
Source, runtime and model admission bind each future preparation separately.

From a standalone source checkout, prepare inputs and initial checkpoints with
no action, query or learning:

```sh
env OMP_NUM_THREADS=1 OPENBLAS_NUM_THREADS=1 MKL_NUM_THREADS=1 \
    VECLIB_MAXIMUM_THREADS=1 NUMEXPR_NUM_THREADS=1 \
    python benchmarks/retention/actual_outcome_chamber.py \
    --prepare --out /tmp/cadence-retention-prepared
```

The preparation copies the continuing-interaction and memory guides and the
actual-outcome, feedback, continuation and memory-checkpoint tests into the capsule as
bridges. The response-protection guide and its two tests, which preparations up to
release 0.84.3 also copied, left the library with the temporal patch.

No sibling project or private evidence directory is required. Default receipts
record formal evidence as `omitted_not_checked`. An explicit
`--formal-source /path/to/CadenceMission` copies all five declared Lean files,
binds their hashes and records `source_snapshots_bound_not_rechecked`; missing
files fail before construction. The instrument does not run Lean or certify a
general memory theorem. Runtime masked-store arithmetic and equation checks
remain independent of those optional source snapshots.

The amplitude and continuation instruments require a caller-selected,
source-bound reference capsule. They do not import local historical evidence
automatically. Preparation is separate from an explicitly reviewed scientific
execution; the commands above do not launch a campaign.

## What changed

Four complete original founder-0 restored checkpoints were fixed before the new
run: orthogonal exposures 0/128/512 and correlated exposure 0. Each forked into
two continuing lives with identical complete arrays, RNG, memory, critic,
optimizer, trace and learning genes. Architecture, ports, capacity, rates,
salience, lateral wiring and decay=0 were unchanged. No teacher supplied actions
or outcomes. Every public sampled action received its own executed world reward.
Persistent C remains 8×2; the fixed 8×8×2 strength array contains C+F, with no
additional allocated F or growing experience bank.

Both arms received the same cue identities and number of opportunities through
world A, reversed world B and restored world A. Full-only received complete
prototypes. Component coverage also experienced each physical one-component
deletion at amplitude 1. These were **additional kinds of TRAIN information**,
not extra outcomes or an architectural improvement. The original .75/1.25
partial cues and noisy reserved instances remained untrained. Evaluation used
teacher-free cold clones, including graph/store lesions; the main lives were
never reset.

The retained causal audit had found that identical paired TRAIN features left
their initial random outgoing-weight differences unchanged. More complete-cue
experience cannot directly identify that difference. The present result supports
repair through ordinary discriminating experience before adding a mechanism;
it does not establish unlimited generalization from redundant observations.
See the [prewritten continuation protocol](COMPONENT_COVERAGE_PROTOCOL.md).
