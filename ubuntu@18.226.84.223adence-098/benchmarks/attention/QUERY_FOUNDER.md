# Ordinary query-seam initialization control

This proposed component experiment changes one initial condition: the
efficacies of the existing reciprocal query/association contacts. It tests
whether starting those contacts from the ordinary projection distribution,
rather than exactly zero, changes acquisition of the same two-binding task.
It declares no behavioral result or library default change.

The frozen reader gives each head live query/read ports in the same coupled
equilibrium. Its query/association contacts start at zero and remain plastic.
The saved-lesson checks found a nonzero local query-interface update; zero
initialization is therefore a bootstrapping hypothesis, not an identified
missing gradient. The earlier learned-reader campaign and its exact
512-round continuation failed their behavioral gates. Their results remain
evidence for the original initialization.

## The one changed factor

query_founder.py first calls the unchanged brain factory.
At `query_scale=0`, it retains the original graph and parameters exactly. At
`query_scale=1`, each head receives one isolated ordinary
`Projection("query", "association")` draw through the public `Genome` and
`develop` API, mapped onto its existing reciprocal contacts. Ordinary
projection defaults supply the scale, signs and fan scaling. No neuron,
contact, head role, address label, output assignment or learning term is
added. Initialization runs once on each fresh brain, before its first event.
Those synapses remain live and plastic throughout later prefix/query settles.

Each draw uses `SeedSequence([founder, head]).spawn(1)[0]`. These independent
initializer streams leave the original factory and action RNG streams
untouched. This is the ordinary projection **distribution in a separate
stream**, not a replay of the full factory with a modified genome. The
record includes the seed namespace, ports, draw digest and before/after
parameter digests. Connectome contact metadata stays unchanged; the record
identifies the controlled initial efficacy values.

All parameters outside these query contacts, biases, log gains, optimizer
arrays, counters, graph class, memory boundary and resource layout are
preserved. Plain exposed controls have no query ports and receive no
parameter change. Constructor checks establish those custody properties;
they do not establish learned behavior.

## Required comparison

The proposed point keeps the existing task, teacher, local update,
agreement energy, coupling, numerical qualification and behavioral floors.
Its protocol must bind the initializer and the complete executed source.
The old zero-initialized positive capacity receipt remains a baseline; it
cannot admit the changed reader. New matched exposed and supplied-read
capacity controls must pass before learned-reader cells open.

The learned comparison starts with H2 on both development founders. Any
subsequent H1, width, duplicated-port and work controls must use the same
initializer setting and retain their full results, refusals and costs.
Missing or incomplete controls establish no parallel-head advantage. This
proposal opens no fresh confirmation founders and changes no original
acceptance gate. The campaign protocol owns execution order and host limits.

## Interpretation limits

Ordinary nonzero contacts can change attractors, settling work and stability
on prefix events as well as queries. Independent draws do not guarantee
useful head specialization or improved conditioning. Read/cortex contacts
already differ between heads, so the original heads were not exactly
symmetric.

Earlier exposed and supplied-read controls also failed held-pair transfer.
Held-out failure therefore does not isolate address learning or head count;
it can include cortical compositional transfer. Passing acquisition alone
would not resolve that limit. Any useful parallel-head claim still needs
the complete behavioral, memory-causality and resource comparisons in the
[parallel-head assessment](PARALLEL_HEADS_ASSESSMENT.md).

This raw-input component control tests coupled retrieval and acquisition.
It does not establish contextual meaning codes, integrated continuing
behavior or a supported public attention lifecycle.

## Measured outcome

All four [matched capacity cells](results/query-founder-capacity.json) complete
512 rounds and acquire every trained pair without action or lesson refusals.
The [learned-reader cells](results/query-founder-h2.json) stop on query refusals
after 297/182 rounds. Their trained/all-case panels refuse; both held panels
complete but score 0/16. This initial-condition test is negative. It opens no
retention, resource comparison, confirmation or longer-world evaluation, and
does not justify changing a library default.
