# Tutorials

A tutorial follows one application from its first brain to its use: the order in which the
problems appeared, how each was measured, and which part of the library answers it. The
[guides](../README.md) own the operations and their contracts; a tutorial links to them and
does not restate them. Readings in a tutorial are from that application alone, and no chamber
of the library measures them.

| Tutorial | What it covers |
| --- | --- |
| [Cadance: a minimal techno stream generator](minimal-techno.md) | A brain of 213 motor slots that writes the next bar of an endless stream: the baseline of repeating, a copy path beside a learned code, earlier bars as inputs, lessons by slot, why a lower error is not better play, and what a player may do to the brain's bar |
