# Experimental scope

The population model repairs one connected graph using live state and optional
exact-error readback. All populations participate in the same solve; outputs
are selected states from a qualified answer. See [the quickstart](QUICKSTART.md)
and [patch equations](DRSN.md).

<a id="system-2-warning"></a>

## Optional recursive observation

An observer reads current states and errors and returns influence through the
shared energy. Error readback is implemented and tested. Its advantage on a
task, automatic recruitment on surprise and independent observer clocks remain
experiments. Ordinary connected populations are the control for that work.

The default System 1 entry is [Brain.compose](../brain.md). It includes
working trace and consolidating associations; its optional System 2 regions
return neural-state feedback. This advanced population model provides a distinct
exact-error mathematical construction. Neither mechanism by itself establishes
an automatically useful routine → disturbance → correction → retained routine
cycle.

Current disagreement, a miss of an earlier forecast and an unmet goal are
separate quantities. A stationary state can still predict reality poorly.
Retained activity can reduce repair work; explicit `History` supplies recent
context. Learned relations persist, but competing learning can overwrite them.

## Credit and continuation

`Reinforcement` defaults to `credit_horizon=1`. Larger horizons change return
construction and replay cost; they do not supply learned planning. The
[live guide](LIVE.md) explains actual action acknowledgments and outcome ownership.

Save the complete application continuation, including body state and pending
outcomes. Checkpoints validate their implementation sources. APIs and saved
formats may change during this experimental phase; no migration layer is promised.

Further work has [individual GitHub owners](https://github.com/muellerberndt/cadence/issues),
including automatic correction, useful recall, durable capacity and GPU execution.
